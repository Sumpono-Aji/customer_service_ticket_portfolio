# Customer Service Ticket Management System
##Project awal(Aji)
Project portfolio Python sederhana untuk mensimulasikan pekerjaan Customer Service / Data Entry.

## Teknologi
- Python 3.9+
- SQLite
- CSV
- Standard Library Python

Tidak membutuhkan library tambahan.

## Fitur

1. Input tiket customer
2. Nomor tiket otomatis
3. Data customer
4. Kategori masalah
5. Prioritas masalah
6. Status tiket
7. Catatan solusi/tindakan CS
8. Pencarian tiket
9. Dashboard customer service
10. Export laporan ke CSV
11. Database SQLite lokal

## Cara menjalankan

Buka Command Prompt di folder project:

    python app.py

Jika `python` tidak dikenali:

    py app.py

Saat pertama kali menjalankan program, pilih:

    8

untuk memasukkan data demo.

Kemudian pilih:

    1

untuk melihat dashboard.

## Contoh alur kerja

Customer menghubungi CS karena pembayaran belum masuk.

CS kemudian:

1. Membuat tiket.
2. Mengisi identitas customer.
3. Memilih kategori Payment.
4. Menentukan prioritas High.
5. Menulis detail masalah.
6. Mengubah status menjadi In Progress.
7. Menulis tindakan/solusi.
8. Mengubah status menjadi Resolved.
9. Mengekspor laporan ke CSV.

## Deskripsi CV

Customer Service Ticket Management System — Personal Python Project

Developed a Python-based customer service ticket management system to record customer information, categorize inquiries, prioritize cases, track ticket status, document solutions, search customer cases, and export service reports to CSV.
